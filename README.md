# SCIOOL Trade X Pro

SCIOOL Trade X Pro combines the premium responsive design language of Roadside Pro XR with the existing TradeX trading research platform.

## Included

- Roadside X-inspired floating navigation and glass-panel design
- SCIOOL Trade X Pro branding
- Responsive desktop and web command center
- Live Forex scanner architecture
- Multi-pair Market Radar
- Multi-timeframe analysis
- 250 executable indicator modules
- Quantum AI and explainable signal tools
- Strategy Builder
- Strategy Lab and backtesting
- Historical Replay
- Trade Journal
- Learning Center
- Advanced Reports
- Risk Governor
- Integration Center
- AI Assistant
- Twelve Data private-key launch support
- Pocket Option authorized connector slot

## Setup

```bash
chmod +x setup_tradex.sh
./setup_tradex.sh
```

Run on Linux:

```bash
flutter run -d linux
```

Run in Chrome:

```bash
flutter run -d chrome
```

## Important limitations

- Live standard-Forex data requires a Twelve Data API key.
- Pocket Option execution remains locked until an authorized connection method is available.
- Some advanced AI modules are rule-based research tools rather than trained predictive models.
- No profit or win rate is guaranteed.
